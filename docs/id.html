Semua yang dibutuhkan untuk Journaling dan membuat Catatan.

Fitur JurnalTX dikelompokkan menurut apa yang ingin Anda lakukan.

Menulis

Format otomatis

Tebal, miring, garis bawah, pangkat atas dan bawah langsung terformat dari sintaks Markdown.

Heading tiga tingkat

Gunakan #, ##, dan ### untuk menyusun struktur catatan.

Kode dengan warna sintaks

Inline code dan blok kode diwarnai sesuai bahasa pemrograman.

Tabel

Buat tabel dengan mudah dengan format Markdown.

Alert dan callout

17 kategori dalam bahasa Inggris dan Indonesia, dari NOTE sampai HASIL.

Kutipan dan checklist

Checkbox bisa diklik langsung. Tugas selesai berubah warna dan diberi tanda centang. Buat kutipan hanya dengan ketik karakter >.

Menghubungkan

Link antar catatan

Ketik [[ lalu beberapa huruf. Daftar catatan yang cocok muncul tepat di bawah baris Anda.

Catatan baru lewat link

Klik link ke catatan yang belum ada, dan halamannya langsung dibuat.

Link eksternal

Tulis [nama](url), lalu Ctrl+klik untuk membuka di aplikasi bawaan sistem.

Cari dan buat dari satu kotak

Ketik judul di sidebar untuk menyaring. Tekan Enter bila belum ada untuk membuat catatan baru.

Berkas

Upload file

Ketik /, pilih Upload File. Link-nya muncul di catatan dan bisa diklik.

Upload gambar

Gambar tampil sebagai pratinjau langsung di halaman catatan atau jurnal.

Daftar file dan cek link

Halaman File List menunjukkan setiap file yang ter-upload di folder Assets dan catatan atau jurnal yang terhubung dengan file tersebut. File yang tidak terhubung akan ditandai ⛓️‍💥.

Aman dari salah hapus

Menghapus catatan tidak ikut menghapus file di Assets. Penghapusan file dilakukan manual dari File List.

Jurnal dan pencarian

Satu halaman per tanggal

Saat dibuka, JurnalTX menampilkan jurnal hari ini. Setiap tanggal punya halamannya sendiri.

Kalender jurnal

Tanggal yang sudah berisi teks diberi tanda. Ikon kalender bisa diganti dengan gambar PNG Anda.

Scrapping Text (1.1.0)

Cari teks di seluruh jurnal dan catatan, lalu klik hasilnya untuk langsung menuju bagian tersebut.

Rename dan Hapus

Klik kanan catatan di sidebar untuk mengganti judul atau menghapusnya.

Data dan tampilan

Simpan real-time sebagai Markdown

Setiap ketikan langsung tersimpan ke folder Note dan Journal, siap dipindah ke aplikasi lain.

Menu klik kanan lengkap

Copy, Cut, Paste, Undo, Redo, Select All, Insert Emoji (Ctrl+;), dan Change Case.

Pengaturan warna

Ubah tampilan lewat ikon Settings atau berkas custom.css.

Tema kustom

Tambahkan tema XML GtkSourceView sendiri ke gtksourceview-5/styles.

Sintaks yang sudah Anda kenal.

Tidak ada format khusus yang perlu dipelajari. Jika Anda pernah menulis Markdown, Anda sudah bisa memakainya.
