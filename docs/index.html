Everything you need to write journal and take notes

JurnalTX features, grouped by what you want to do.

Writing

Auto-formatting

Bold, italic, underline, superscript, and subscript are formatted instantly from Markdown syntax.

Three heading levels

Use #, ##, and ### to structure your notes.

Syntax-highlighted code

Inline code and code blocks are colored according to the programming language.

Tables

Easily build a tables with the Markdown format.

Alerts and callouts

17 categories in English and Indonesian, from NOTE to HASIL.

Quotes and checklists

Checkboxes are clickable. Completed tasks change color and get a check mark. Making simple quote by typing > symbol.

Connecting

Note-to-note links

Type [[ and a few letters. Matching notes appear right below your line.

Create notes through links

Click a link to a note that doesn't exist yet, and the page is created for you.

External links

Write [name](url), then Ctrl+click to open it in your system's default app.

Search and create from one box

Type a title in the sidebar to filter. Press Enter if it doesn't exist to create a new note.

Files

Upload files

Type / and choose Upload File. The link appears in your note and is clickable.

Upload images

Images show as live previews on the note or journal page.

File list and link check

The File List page shows every file in the Assets folder and the notes or the journals that use it. Orphaned files are marked ⛓️‍💥.

Safe from accidental deletion

Deleting a note does not delete files in Assets. Files are removed manually from File List.

Journal and search

One page per date

On launch, JurnalTX opens today's journal. Every date has its own page.

Journal calendar

Dates that already contain text are marked. The calendar icon can be replaced with your own PNG.

Scrapping Text (1.1.0)

Search text across all journals and notes, then click a result to jump straight to it.

Rename and delete

Right-click a note in the sidebar to rename or delete it.

Data and appearance

Real-time Markdown storage

Every keystroke is saved to the Note and Journal folders, ready to move to another app.

Full right-click menu

Copy, Cut, Paste, Undo, Redo, Select All, Insert Emoji (Ctrl+;), and Change Case.

Color settings

Change the look from the Settings icon or the custom.css file.

Custom themes

Add your own GtkSourceView XML theme to gtksourceview-5/styles.

Syntax you already know.

There's no special format to learn. If you have ever written Markdown, you can already use it.
